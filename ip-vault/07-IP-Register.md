## Redaction Policy

> [!blackbox] What This Vault Never Contains
> Credentials · Production URLs · Policy SQL · RPC source · Admin tooling · Live operational data · Partner identifiers · Exact permission matrices

| Excluded | Reason |
|----------|--------|
| API keys and secrets | Direct compromise risk |
| Infrastructure hostnames | Attack surface mapping |
| Security policy logic | Bypass research |
| Algorithm implementations | Trade secret protection |
| Internal QA mechanisms | Privilege escalation risk |
| Real organization data | Privacy and sensitivity |

Safe alternative always documented: *"Protected component — interface published, implementation withheld."*

## Verification Checklist

Before any external publication or IP deposit:

- [ ] No credentials or tokens
- [ ] No production infrastructure identifiers
- [ ] No exact security predicates
- [ ] No real partner or personnel data
- [ ] Code snippets are abstract pseudocode only
- [ ] Black-box labels on all protected components
