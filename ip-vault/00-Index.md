## Design Principles

> [!blackbox] Disclosure Boundary
> This vault communicates **what** the platform does and **why** it is proprietary.  
> It never exposes **how** protected algorithms, policies, or credentials operate internally.

- Warm, institutional tone — not technical documentation
- Abstract interfaces — not production source code
- Modular cards — one idea per surface
- Growa green accents — signal protected IP, not decoration
